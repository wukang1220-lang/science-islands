# 自然科島嶼

國中自然科（108 課綱）學習網站：生物、物理、化學、地科、跨科五個群島，依課程性質分成 33 座島、132 節，不分年級。

- 網站：https://wukang1220-lang.github.io/science-islands/
- 每一節有重點整理（關鍵詞紅字）、圖解、互動說明、常見迷思，以及 6 題練習題和 2 題會考題型；答對整節就能集章。
- 每座島有一座會考塔；首頁可以做模擬會考、弱點診斷和錯題本。
- 走進島：低多邊形 3D 島嶼，每一節是一座展覽館，館主會講解、出題；還有任務本、換裝、集章兌換所、答題道具和合成工坊。
- 重點、題目、迷思、圖解和程式皆為自編；課本、講義與題庫只用來確認範圍。

## 檔案

| 路徑 | 內容 |
|---|---|
| `structure.json` | 群島、島、章、節（由 `make_structure.py` 產生） |
| `content/*.json` | 各節重點（`**紅字**`）、練習題與會考題型 |
| `halls/*.json` | 每一節的展覽館：館名、樣式、屋頂裝飾、說明與常見迷思 |
| `scenes.json`、`guides.json` | 3D 島上的展示、館主台詞和每座島的領航員 |
| `extras.json` | 每一節用到的圖解與互動說明 |
| `weights.json` | 歷屆會考各島出題數（模擬會考加權用） |
| `art/figs/*.svg` | 圖解；`python -I art/check_svg.py art/figs` 檢查 |
| `tpl.html` | 頁面模板（版面、練習、互動說明、3D 島嶼與遊戲） |
| `build.py` | 檢查內容並產生 `docs/index.html`（GitHub Pages）與上一層的 `science-islands.html` |

## 建置

```
python -I build.py
```

題目只能往後新增、不要調整既有順序（`qbase.json` 會擋下減少題數；答題紀錄用「節.題號」記錄）。
